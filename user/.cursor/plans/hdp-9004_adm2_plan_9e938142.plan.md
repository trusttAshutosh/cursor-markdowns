- Manual cap annotate: [AssignCapService.annotateForManualAssign](trustt-platform-task-allocation/src/main/java/com/trustt/taskallocation/assignment/AssignCapService.java) - keep at-cap rows, set `canAssign = openTaskCount < manualMax`
- Config: [BkycAssignConfig.getManualMaxOpenTasks](trustt-platform-task-allocation/src/main/java/com/trustt/taskallocation/plugin/bkyc/config/BkycAssignConfig.java) key `trustt.taskallocation.bkyc.assign.manual.max.open.tasks` default 15
- Fail-closed Actor errors: `4000180` / `4000181` - surface as public error envelope, never a silent empty list
- Do **not** call `getAllPincodeEligibleForAutoAssign` (internal pageSize 500 loop)

## Public contract (locked with Jira + solution §7.4)

`POST /task-allocation/api/v2/getEligibleAgentsForTask` (gateway `/api/v2/task-allocation/getEligibleAgentsForTask`).

Request: `taskId` (required), `mode` PINCODE / DISTANCE / HYBRID (required), optional `pincode`, `searchText`, `pageSize` / `offset`, `customerLat` / `customerLng`.

Response: `pageSize`, `offset`, `numberOfRecords`, `agentList[]` of `{ agentDetails: { id, agentCode, agentName, pincode, addressLine, openTaskCount, maxManualTasks, canAssign, distanceKm } }`. Map internal `agentId` to `agentDetails.id`. No tab counts.

## Behavior locks

- Phase 1 corporate: same as ADM1 - `BkycAssignConfig.getCorporateId()`. Load task by `taskId`; reject if missing, wrong type, or `task.corporateId` != configured corporate.
- Prefill: blank request `pincode` / lat / lng come from the task; request values override.
- PINCODE / HYBRID: after prefill, pincode still blank -> validation error (do not wait for Actor `400001`).
- DISTANCE / HYBRID: after prefill, coords still missing -> call the existing lazy geocode in [AgentTaskService](trustt-platform-task-allocation/src/main/java/com/trustt/taskallocation/task/service/AgentTaskService.java) (extract a small shared helper; do not copy-paste). Still missing -> validation error.
- Public paging: default `pageSize=20`, `offset=0`, max **100**. Reject out of range (do not clamp to 500; do not copy ADM1 default 10).
- Soft-block only: agents at cap 15 stay in the list with `canAssign=false`. Hard reject is ADM3.
- `searchText` passes through to Actor as-is.

## Error codes (new constants class)

Do **not** reuse ADM1 `4000045`-`4000049` or SMS `4000045`/`4000046`. Propose ADM2:

- `4000050` invalid mode
- `4000051` task not found / not BKYC / wrong corporate
- `4000052` corporate unset
- `4000053` pincode required
- `4000054` customerLat/Lng required
- `4000055` paging

Actor transport still `4000180` / `4000181`.
